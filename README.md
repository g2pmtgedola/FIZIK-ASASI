# ⚛️ FizikAsasi: Platform Pembelajaran Interaktif Fizik Asasi Sains UiTM (Khas Untuk Amal)

Selamat datang ke platform pembelajaran interaktif Fizik Asasi Sains UiTM yang dibina khusus untuk membantu **Amal** memahami konsep fizik dengan mudah, santai, visual, dan berkesan tanpa perlu menghafal secara buta tuli!

## 🎯 Kandungan Mengikut Sukatan Peperiksaan (UiTM Dengkil)

Platform ini merangkumi 4 bab utama daripada nota kuliah pensyarah (*Hasnorhafiza Husni, UiTM Dengkil*):

1. **Bab 7: Rotational Motion (Gerakan Putaran & Membulat)**
   - *Konsep*: Sesaran sudut ($\theta$), Halaju sudut ($\omega$), Pecutan sudut ($\alpha$).
   - *Hubungan Linear vs Sudut*: $v = r\omega$, $a_t = r\alpha$.
   - *Pecutan & Daya Memusat*: $a_c = \frac{v^2}{r} = r\omega^2$, $F_c = m\frac{v^2}{r}$.
   - *Aplikasi Penting*: Jalan Rata ($\mu_s = \frac{v^2}{rg}$), Jalan Mencondong/Banked ($\tan\theta = \frac{v^2}{rg}$), dan Gelung Menegak/Vertical Loop ($v_{top} = \sqrt{gR}$).
   - *Simulasi*: Piring Berputar Bonnie vs Klyde dengan Vektor Halaju & Pecutan live.

2. **Bab 9: Solids & Fluids (Pepejal & Bendalir)**
   - *Prinsip Archimedes*: Daya Apungan $F_B = \rho_{fluid} V_{displaced} g$.
   - *Terapung vs Tenggelam*: Nisbah ketumpatan & berat ketara neraca spring.
   - *Deformasi Pepejal*: Stress ($\sigma = F/A$), Strain ($\epsilon = \Delta L/L_0$), Graf Stress vs Strain.
   - *3 Modulus Elastik*:
     - Young's Modulus ($Y$): Regangan panjang.
     - Shear Modulus ($S$): Ricihan/anjakan bentuk sisi.
     - Bulk Modulus ($B$): Mampatan isipadu seragam ($\Delta P = -B \frac{\Delta V}{V_0}$).
   - *Simulasi*: Beaker Apungan Archimedes & Pengira Kehilangan Berat Ketara.

3. **Bab 11: Energy in Thermal Processes (Proses Terma)**
   - *Haba vs Tenaga Dalaman*: $1\text{ cal} = 4.186\text{ J}$.
   - *Muatan Haba Tentu*: $Q = mc\Delta T$.
   - *Kalorimetri Terlindung*: $\sum Q = 0 \iff Q_{cold} = -Q_{hot}$.
   - *Haba Pendam*: $Q = \pm mL_f$ (Pelakuran), $Q = \pm mL_v$ (Pengewapan).
   - *Konduksi Haba*: $P = \frac{Q}{\Delta t} = kA\left(\frac{T_h - T_c}{L}\right)$.
   - *Simulasi*: Graf Interaktif Pemanasan Ais ($-30^\circ\text{C}$) $\to$ Air $\to$ Stim ($120^\circ\text{C}$).

4. **Bab 13: Vibrations & Waves (Getaran & Gelombang)**
   - *Hukum Hooke & Tenaga Keupayaan*: $F = -kx$, $PE_s = \frac{1}{2}kx^2$.
   - *Persamaan SHM*: $x = A\cos(\omega t)$, $v = -\omega A\sin(\omega t)$, $a = -\omega^2 A\cos(\omega t)$.
   - *Tempoh Ayunan*: Spring ($T = 2\pi\sqrt{m/k}$), Bandul Ringkas ($T = 2\pi\sqrt{L/g}$).
   - *Sifat Gelombang*: $v = f\lambda$, Laju pada tali tegang $v = \sqrt{F/\mu}$.
   - *Prinsip Superposisi*: Interferens Membina (Puncak + Puncak) & Interferens Memusnah.
   - *Simulasi*: Osilator Spring SHM Real-Time dengan Jejak Graf Sinusoidal.

## 🚀 Cara Menggunakan Platform

1. Buka fail `index.html` terus di mana-mana pelayar web (Google Chrome / Microsoft Edge / Safari / Firefox).
2. **Tiada pemasangan server rumit** — semua fail HTML, CSS, dan JS berjalan terus di komputer atau telefon pintar.
3. Gunakan tab di bahagian atas untuk melompat antara bab atau membuka **Formula Poket Poket / Cheatsheet**.
4. Gunakan **Kalkulator Pantas Fizik** (ikon kalkulator di bucu atas kanan) untuk mengira nilai soalan latihan.
5. Cuba jawab kuiz di akhir setiap bab untuk melihat markah dan jalan kira lengkap!
